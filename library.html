Library

Short tutorials. The patterns that matter.

Branded 20–60s clips will live here. Until then, use these cues so you don’t guess the shape of the lift.

SQ

Squat

Feet planted, knees track toes, stand up like you’re pushing the floor away. Depth you can own.

HG

Hinge

Soft knees, hips back, long spine. Feel hamstrings, not a rounded lower back.

PS

Push

Ribs down, body one piece. Elbows ~45°. Stop before the shoulder dumps forward.

PL

Pull

Start the row with the armpit, not the wrist. Pause a beat at the body.

RN

Easy run

If you can’t speak a sentence, it’s not easy. Slow down. Walk if you need to.
